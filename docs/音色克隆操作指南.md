# 音色克隆操作指南

让你的智能体用**你自己的声音**回答。

---

## 一、在哪录

**没有麦克风的机器录不了。**先确认你的机器有音频输入设备：

```bash
system_profiler SPAudioDataType
```

输出里有 **Input** 段落说明能录；只有 Output 说明**没有输入设备**。

三种可行方案：

| 方式 | 怎么做 | 评价 |
|---|---|---|
| **手机录（最省事）** | iPhone「语音备忘录」录 30~60 秒，隔空投送 / 微信传回电脑 | 手机麦克风通常比外接麦还好 |
| **给电脑插麦克风** | USB 麦克风插上，`brew install ffmpeg`，再跑 `./tools/record_voice.sh 60` | 一劳永逸 |
| **系统自带录音 app** | macOS 26+ 自带 `VoiceMemos.app` | 前提还是有麦克风 |

## 二、录什么样的声音

### 硬性格式要求（平台会拒）

| 项目 | 要求 |
|---|---|
| 格式 | **mp3 / m4a / wav**（手机录音默认 m4a，可以直接传） |
| 时长 | **10 秒 ~ 5 分钟** |
| 大小 | **≤ 20MB** |
| 采样率 | **≥ 16kHz**（手机的都够） |
| 人数 | **只有一个人说话** |

### 质量建议（不拒，但影响效果）

- **时长 30~60 秒**最稳。太短音色不稳，太长容易带进多余噪声。
- **安静房间**，关窗、关空调，别在厨房或临街的房间录。
- **嘴离麦克风 15~25cm**，别太近（会有喷麦的「噗噗」声）。
- **语速正常**，像平时说话一样，**不要念得像播音腔** —— 播音腔克隆出来也不像你。
- **别只念数字和字母**。要包含完整的句子和日常词汇，否则合成时容易把语调学歪。
- 录之前先录 5 秒静音；结尾别突然掐断。

### 一段推荐的朗读稿（约 45 秒）

> 大家好，我叫小智，是这台音箱里的语音助手。
> 平时我会帮人查天气、播报日程、读一些新闻摘要。
> 今天是十一月一号，星期三，下午三点二十，外面有点凉，记得加件外套。
> 如果你想听音乐，直接跟我说歌名就行。
> 遇到听不懂的话，我会老实告诉你我不知道，不会瞎编。

念的时候**别演**，就当在跟朋友说话。

## 三、操作步骤

### 第 1 步：录一段

按上一节录好，存到电脑上。

### 第 2 步：检查素材合不合格（不联网、不花钱）

```bash
# 文件在下载目录的话
./xiaogpt-env/bin/python tools/voice_clone.py check ~/Downloads/voice_sample.m4a
```

输出示例：

```
时长 45.3s / 1.2MB / 44100Hz
素材合格
```

不合格会直接告诉你是哪一条不达标（太短 / 超大 / 格式不对 / 采样率太低）。

### 第 3 步：克隆

```bash
./xiaogpt-env/bin/python tools/voice_clone.py clone ~/Downloads/voice_sample.m4a \
    --voice-id xiaozhi_myvoice \
    --text "你好，我是小智。"
```

**voice_id 命名规则**（平台会拒）：

- 长度 **8 ~ 256** 个字符
- **必须字母开头**
- 只能含**字母 / 数字 / 下划线 / 连字符**
- **不能以下划线或连字符结尾**
- 在账号内**唯一**（重名会失败）

命令做了三件事：上传拿 file_id → 建音色 → **立刻合成一句**。
最后那步别省 —— **克隆出来的音色 7 天没人用会被平台自动清掉**，
合成一次就算激活。

### 第 4 步：设成默认音色

```bash
./xiaogpt-env/bin/python tools/voice_clone.py use xiaozhi_myvoice
```

或者在控制台「音色」页的「克隆音色」卡片里点「刷新」，然后「设为默认」。

> ⚠️ **要记得把「音色来源」切回「MiniMax 音色」。**
选「小爱原生音色」那条路不经过 MiniMax，克隆音色用不上。

### 第 5 步：验证

```bash
# 合成一句（--speak 直接推给音箱）
./xiaogpt-env/bin/python tools/voice_clone.py try xiaozhi_myvoice --speak

# 看账号里现在有哪些克隆音色
./xiaogpt-env/bin/python tools/voice_clone.py list
```

## 四、常见报错对照

| 报错 | 含义 | 怎么办 |
|---|---|---|
| `2038 voice clone user forbidden` | **账号没开通克隆权限** | 去平台实名认证 + 申请开通 |
| `2061 token plan not support model` | 套餐不含这个模型 | 升级套餐 |
| `2013 invalid params, voice_id length` | voice_id 长度不对 | 调到 8~256 |
| `2013 ... voice_id first character` | voice_id 数字开头 | 改成字母开头 |
| `2013 ... voice_id invalid character` | voice_id 里有空格等非法字符 | 只留字母数字_- |
| `2013 ... voice_id last character` | voice_id 以 _ 或 - 结尾 | 改掉最后一个字符 |
| `1043`（ASR 相似度不达标） | 录音里有别人说话或噪声太重 | 重录 |

## 五、在电脑上录（需要麦克风）

```bash
# 装 ffmpeg（Homebrew）
brew install ffmpeg

# 给电脑接一个 USB 麦克风，然后：
./tools/record_voice.sh 60            # 录 60 秒到桌面
./tools/record_voice.sh 90 /tmp/a.wav # 指定时长和路径
```

录音脚本会自动挑输入设备、录成单声道 44.1kHz，
录完直接调用 `voice_clone.py check` 告诉你合不合格。

macOS 会弹窗问「终端想访问麦克风」，要**允许**，否则录出来是空的。
路径：系统设置 → 隐私与安全性 → 麦克风。

---

## 六、合规提醒

克隆自己的声音没问题。**克隆别人的声音**（包括小爱音箱的声音）
在 MiniMax 的条款下需要对方明确授权，平台也会做敏感内容检测。
这条链路是给你自己的声音准备的。
